Três passos, zero instalação

    
Nada de npm ou arquivos locais. A biblioteca vem de uma CDN, só um link no <head>.

    

      
Importe
Cole o link da CDN no seu HTML.

        
<link rel="stylesheet"
 href="https://cdnjs.cloudflare.com/
 ajax/libs/animate.css/4.1.1/
 animate.min.css">

      
Escolha a classe
Sempre as duas juntas: a base e o nome da animação.

        
<h1 class="animate__animated
 animate__bounce">
  Olá!
</h1>

      
Dispare com JS
Adicione a classe quando quiser e remova ao terminar.

        
el.classList.add(
 'animate__animated',
 'animate__tada');
el.addEventListener(
 'animationend',
 () => el.classList.remove(
  'animate__animated',
  'animate__tada'));

    

    

      
Classes extras que você pode misturar:

      animate__delay-2sanimate__slowanimate__faster
      animate__infiniteanimate__repeat-3--animate-duration
